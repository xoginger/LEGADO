# Local hardware guide (English)

Companion to [`../es/equipo-local.md`](../es/equipo-local.md). Agent Store path `/cursor/stores/self/docs/equipo-local.md` stays the project working copy.

## User context

- Currency: **MXN**
- Starting from zero (no machine yet)
- No fixed budget cap
- **Default advice:** “Recommended” range for a long-term legacy
- Prices below are **approximate Mexico market ranges**, not store quotes

## Ranges (approx. MXN)

| Band | Approx. MXN | Fits |
| --- | --- | --- |
| Entry | $18,000 – $30,000 | 7B chat; tight for 14B |
| **Recommended** | **$30,000 – $55,000** | **Default** — 7B–14B + RAG headroom |
| Comfortable | $55,000 – $95,000+ | Multi-model, voice+avatar later |

Each band: **Apple Silicon Mac** (unified RAM; Ollama/MLX) vs **Windows/Linux PC + NVIDIA** (VRAM + system RAM; Ollama).

## Text chat vs voice + avatar

MVP is **text only**. Local cloned voice + talking avatar raise RAM/VRAM/disk needs — prefer high end of Recommended or Comfortable if you know you want presence media on the same box.

## Kiosk (“AI only at power-on”)

The OS is **not skipped**; it is **hidden/locked** (macOS single-app / Linux kiosk). That work is a **later phase** — buy for chat RAM/VRAM first.

## Capture for later voice/avatar

Clean speech audio (minutes), face photos, optional short talking video — ask whether the owner already has them; not required for the text MVP.
