# Brand assets / Assets de marca

SVG and PNG icons for LEGADO (book + seedling mark).

| File | Use |
| --- | --- |
| `legado-mark.svg` | Primary mark (headers, README, landing) |
| `legado-icon.svg` | Compact favicon SVG |
| `favicon-16.png` / `favicon-32.png` | Browser favicons |
| `apple-touch-icon.png` | iOS home screen (180×180) |
| `icon-192.png` / `icon-512.png` | PWA / app icons |

Canonical source: `packages/shared/assets/`. Copies also live under `apps/*/public/brand/` and this folder for GitHub Pages / marketing.
